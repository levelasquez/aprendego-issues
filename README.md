# Reportes de AprendeGo

Aquí se reportan los errores que encuentres en las lecciones de AprendeGo, un curso gratuito de Go
en español.

Para reportar uno, usa el enlace "¿Encontraste un error en esta lección?" al final de cada lección:
abre el formulario con la lección ya indicada. También puedes abrir un issue nuevo desde la pestaña
**Issues** y elegir **Error en una lección**.

Este repositorio solo tiene la plantilla de reportes; el código del curso no está aquí.

Proyecto comunitario, no afiliado ni respaldado por el equipo de Go ni por Google.
